# 지도와 궤적 그림

- `fig6_goal4_ours_vs_pixnav_run005.png`: 바로 사용할 완성 그림.
- `.svg`: 글자·궤적을 편집할 수 있는 벡터 파일. 외부 이미지 파일 의존 없음.
- `.pdf`: 문서 삽입용.
- `map_background.png`: 궤적 없는 기존 출판용 지도.
- `map_coordinates.json`: 이 원본 지도 픽셀과 m 좌표의 대응.

두 방법 모두 Goal 4이며 그림 오른쪽 위 축척은 1m입니다. 초록색은 ESCAPE-Nav, 보라색은 Direct-goal PixelNav입니다.

CSV에서 시간에 따른 궤적 영상을 만들 때 원본 지도 좌상단 픽셀의 중심을 기준으로 다음 대응을 사용합니다.

```text
x_m = -3.887 + column * 0.05
y_m = 13.091 - row * 0.05
column = (x_m + 3.887) / 0.05
row = (13.091 - y_m) / 0.05
```

원본 지도는 490×520 픽셀입니다. 완성 비교 그림은 X=[-1.8,13.5], Y=[-6.3,4.1]m 영역을 잘라 렌더링했으므로, 완성 그림 PNG에 위 픽셀 식을 직접 적용하면 안 됩니다. 가로·세로 축척을 동일하게 유지하세요.

이는 기존 그림의 표시 시작점 기준 지도 배치를 재사용한 것입니다. 새 ICP 정합이나 독립 측정 GT가 아닙니다. 원본 자유 영역의 구멍을 메우거나 궤적을 반전·평활화하지 않았습니다.
