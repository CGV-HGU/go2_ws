# 2026-09-14 라이다 실시간 점검

점검 요청 이후 사용자가 라이다의 이상 소음과 이전보다 느려 보이는 회전을 보고했다. **점군 수신은 확인했지만 기계적 정상 판정은 보류한다.** 음성·영상 또는 기준 회전수와의 비교 없이 소음 원인이나 모터 고장을 확정할 수 없다.

## 수행 범위

- ROS domain 0에서 구독만 수행했다. 센서 설정·모터 속도·주행 명령·서비스 호출·재부팅은 하지 않았다.
- 첫 측정: 17:27:56~17:28:36 KST, 약 40초. 재측정: 약 25초.
- 유선 본체 192.168.123.161 ping 3/3 응답, 0.146~0.331ms. eth0 오류·드롭 카운터는 관찰 시 모두 0.
- 점검 당시 Jetson의 ESCAPE 제어기, RTAB-Map, sensor_input은 실행 중이지 않았다. 본체 자체 센서 토픽을 직접 구독했다.
- 첫 측정 중 사용자가 로봇을 움직이거나 만졌음을 확인했다. 이 구간의 오도메트리 변화를 정지 상태의 드리프트로 판정하지 않는다.

회전 속도와 손실률은 **토픽의 원시 수치**다. 공개 LidarState.msg에는 단위와 허용 범위가 없다. RPM/Hz 또는 손실률 %로 임의 변환하지 않았다. 과거 `.local-data`의 JSON/JSONL/log 검색에서 동일 회전 필드 기록을 찾지 못했으며, 모든 rosbag을 조사한 것은 아니다. 따라서 '전보다 느려짐'의 정량 비교는 아직 불가능하다.

25초 재측정에서도 원본·보정 점군 각각 387프레임, 약 15.47Hz, 무효 프레임 0을 확인했다. `com_rotation_speed` 원시값은 233.490~272.817, 중앙값 258.219였다. 이는 센서 출력이 지속된다는 근거이지 모터·베어링·간섭·전원 상태의 정상 인증이 아니다.

원본과 보정 점군은 좌표계와 필터링이 다르다. 보정 점군은 odom 좌표계이므로 XYZ 절댓값을 로봇에서의 측정 거리로 읽으면 안 된다. 현재 `sensor_geometry.cloud_xyz`는 XYZ=0을 원래 좌표계에서 제거한다. 이 기존 코드를 읽었으며 본 점검에서 수정하거나 파이프라인을 기동하지 않았다.

초기에는 `/utlidar/server_log` 구독을 포함할 때 Foxy DDS 문자열 역직렬화 오류가 발생했다. 이 토픽을 제외한 센서 재측정에서는 해당 오류가 없었다. 점군 XYZ 디코딩 오류는 두 측정 모두 0이었다. 문자열 진단 로그 경로 문제와 라이다 점군 출력을 구분한다.

## 공식 자료와 한계

[Unitree L1 사용자 설명서](https://oss-global-cdn.unitree.com/static/52b72f707b304d229d4321eea223738f.pdf)는 고속·저속 모터 구조, 외부 간섭 시 상태, 재시작 및 지속 문제의 제조사 문의를 설명한다. 단독 L1 제품의 공시 주파수를 Go2의 ROS 점군 프레임 수나 단위가 명시되지 않은 상태 필드와 직접 비교하지 않았다.

[공식 LidarState.msg](https://github.com/unitreerobotics/unitree_ros2/blob/master/cyclonedds_ws/src/unitree/unitree_go/msg/LidarState.msg)는 위 상태 필드를 정의하지만 회전 속도의 단위·정상 범위·오류 비트 의미를 설명하지 않는다. 공개 L1 MAVLink SDK의 회전 주기 필드를 현재 Go2 상태값과 동일하다고 가정하지 않았다.

## 지금의 판단

**데이터 수신 장애나 전부 무효인 원본 점군은 재현되지 않았다. 이상 소음·체감 감속은 해결되지 않은 하드웨어 점검 항목이다.** 현재 자료만으로 정상 또는 모터 고장을 확정하지 않는다.

주행 전 본체 전원을 끄고 회전체 주변의 이물·간섭·외관 손상을 확인하는 것을 권한다. 회전체를 손으로 강제로 돌리거나 분해하지 않는다. 외관 이상이 없더라도 다시 켰을 때 같은 소음과 감속이 지속되면 소음 영상과 본 상태 로그를 함께 제조사/관리자에게 전달하는 것이 다음 단계다. 전원 조작이나 현장 점검은 이번 원격 점검에서 수행하지 않았다.

`summary.json`, `samples.json`, `cloud_snapshots.npz`는 첫 측정이며 `sensors_without_log/`는 재측정이다. 런타임 및 기존 실험 로그는 변경하지 않았다.
