# Direct PixelNav 4번 정량평가 기록

실제 목표 발송 후 35.40초 동안 오도메트리 기준 4.91m 이동했습니다. 정책 21번째 출력은 STOP(0)이며, 그 전 20개의 이동 명령은 모두 실행됐습니다. 종료 시 목표까지 7.46m, 도착 반경 진입 없음, SR 기여 0으로 기록됩니다. VLM 호출은 0건입니다.

기록 무결성 검사 통과. CSV와 센서 원본, 정책 입력/출력, 종료 이유가 보존되어 있습니다. 입력한 단일 0으로는 개입/접촉/진로 방해를 확정하지 않아 현장 확인을 요청했습니다. SPL은 최단경로 기준 미제공으로 기존 exporter가 null을 기록했습니다.

출발 전 노드 오류였던 direct_goal-goal-4-001은 started=false로서 주행 SR 분모에 포함하지 않습니다. 이번 회차는 실제 시작된 정책 종료 실패로 별도 보존하며, 한 회차만으로 Ours와의 전체 성능 비교를 확정하지 않습니다.

현장 후속 확인: 사용자가 개입·접촉·진로 방해 모두 없었다고 명시했습니다. 원본을 수정하지 않고 field-report-confirmation.json과 episode.reviewed.json에 보완했으며 episode-metrics.csv에 정량 요약을 저장했습니다.
