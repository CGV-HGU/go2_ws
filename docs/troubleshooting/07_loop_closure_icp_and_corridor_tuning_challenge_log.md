## 2. 🔬 핵심 원인 분석 (Root Cause Analysis)

### 과제 A. 루프 클로저 미체결 (ICP 20cm의 벽)
* **현행 파라미터**:
  * `Icp/MaxCorrespondenceDistance`: `0.20m` (20cm)
  * `Icp/MaxTranslation`: `0.20m` (RTAB-Map C++ 코어 기본값)
  * `RGBD/LoopClosureIdentityGuess`: `false`
* **병목 메커니즘**:
  * 71m 왕복 후 출발점에 복귀했을 때 누적 드리프트가 약 1.0m 발생함.
  * 전면 카메라가 출발점 시각 단어(DBoW2)를 인식하더라도, 라이다 ICP의 점 탐색 반경(`0.20m`)과 최대 이동 허용량(`0.20m`)이 너무 엄격하여 **1.0m 떨어진 점군을 매칭하지 못하고 강제 기각(Reject)**됨.
  * 결과적으로 1m 갭이 0으로 수렴하지 못하고 영구 잔존함.

### 과제 B. 벽 밀착 주행 시의 35cm 블라인드 컷오프
* **현행 파라미터**:
  * `Grid/RangeMin`: `0.35m` (35cm)
  * `Grid/MinGroundHeight`: `-0.45m`, `Grid/MaxGroundHeight`: `-0.20m`
  * 2D 맵 추출기: `pts[0::6]` 다운샘플링 및 `valid = (lx**2 + ly**2 >= 0.35**2)`
* **병목 메커니즘**:
  * 4족 보행 로봇의 다리와 머리가 장애물로 오인식되는 것을 방지하기 위해 35cm 근거리 점군은 원천 삭제됨.
  * 로봇이 벽에 20~30cm로 밀착 주행하면, **로봇 몸체와 벽 사이의 바닥 점군이 전부 35cm 컷오프에 걸려 삭제**되므로 2D 맵 상에서 하얀색 바닥으로 칠해지지 못하고 회색으로 남음.

## 3. 🎯 해결 과제 및 튜닝 제안 (Proposed Solutions)

### [과제 1] 루프 클로저 포획력 증대 (ICP & Identity Guess)
* **제안 설정값**:
  ```python
  'Icp/MaxCorrespondenceDistance': '0.40',  # 20cm -> 40cm로 탐색 반경 2배 확장
  'Icp/MaxTranslation': '0.70',             # 20cm -> 70cm로 허용 이동량 확장
  'RGBD/LoopClosureIdentityGuess': 'true',  # 복귀 시 제자리 기준 라이다 정합 유도
  ```
* **리소스 및 안전성 검증**:
  * **Jetson 부하**: 현재 RTAB-Map 프레임 처리 시간은 약 75~100ms (2.0Hz 주기 500ms 중 15~20%만 사용 중). 반경 확장 시 연산량 증가는 약 20~30ms에 불과하여 **총 120~130ms로 자원 여유도 약 75% 유지**.
  * **접힘 방어**: `RGBD/ProximityBySpace: false`가 유지되므로, 시각적 단서 없는 무차별 공간 접힘 위험 없음. 오직 카메라가 출발점을 인식했을 때만 대형 루프 보정이 실행됨.

### [과제 2] 2D 맵 추출기의 광선 추적(Ray-tracing) 보간 도입
* **제안 변경**:
  * `scratch/extract_final_golden_map.py`에서 `ground_cells` 점만 찍는 단순 플로팅 대신, **로봇 포즈 (x_robot, y_robot)에서 장애물 벽면 (x_obs, y_obs)까지 2D Bresenham 선분 추적**을 수행.
  * 시야선 상의 모든 픽셀을 하얀색(Free Space)으로 채워 넣음으로써, 벽면 35cm 블라인드 갭을 완전히 메우고 벽에 딱 붙는 미려한 주행 지도를 완성함.

### [과제 3] 단안 전면 광각 카메라 캘리브레이션
* **현상**: `scratch/go2_front_camera_publisher.py`의 왜곡 계수가 `D = [0, 0, 0, 0, 0]`, `fx = fy = 600` 더미값으로 방치됨.
* **제안 과제**: 8x6 체커보드를 이용해 Go2 전면 광각 렌즈의 실제 왜곡 계수(k1, k2, p1, p2)를 산출하여 적용, 시각 단어(DBoW2) 매칭 신뢰도 극대화.
