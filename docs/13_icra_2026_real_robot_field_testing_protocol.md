## 1. 📍 실물 로봇 실험 환경 구축 및 통제 프로토콜

실물 로봇 실험에서 심사위원들이 가장 강조하는 것은 **환경 변수의 무작위성(Randomness) 차단 및 재현성 확보**입니다.

* **시작점 및 목표점의 물리적 정밀 마킹**:
  * 각 코스별로 로봇의 시작 위치 $(x_0, y_0, \theta_0)$와 목표 구역(Goal Zone)을 바닥에 마스킹 테이프로 고정합니다.
  * 목표 구역은 **반경 $0.5\text{m}$ 이내의 원**으로 설정하고, 로봇의 중심점이 해당 원 내에 들어와 정지했을 때만 성공(Success = 1)으로 인정합니다.
* **외부 환경 변수 통제 및 수치 기록**:
  * **실내 코스**: 조도계(Lux meter)를 활용하여 실험 환경의 조도(예: $300\text{ Lux}$)를 동일하게 유지하거나 수치를 기록합니다.
  * **동적 장애물 코스**: 보행자 장애물의 이동 속도(예: $1.2\text{ m/s}$)와 무대 진입 시점을 타이머 마커로 정밀 통제합니다.
  * **실외 코스**: 지면 상태(건조 자갈 / 젖은 풀밭)와 일광 조건을 기록하여 시도 간 환경 편차를 최소화합니다.

## 2. 📹 센서 데이터 및 주행 궤적 기록 파이프라인 (Data Logging)

실물 로봇이 주행하는 동안 모든 센서 데이터와 궤적이 실시간으로 기록되어야 2D 궤적 플롯 및 정량 지표를 도출할 수 있습니다.

* **`rosbag2` 실시간 데이터 로깅 상시 가동**:
  * 주행 중 카메라 RGB 프레임, LiDAR 점군, IMU, RTAB-Map 오도메트리 위치 좌표($(x_t, y_t)$), S2E 속도 명령치($v_x, v_y, \omega$)를 상시 기록합니다 (`scratch/record_experiment.sh`).
* **Ground Truth 위치 좌표 수집**:
  * RTAB-Map LIVO 오도메트리의 글로벌 좌표 궤적을 수집하여 2D 궤적 비교 그래프(Trajectory Plot)를 추출합니다.

## 3. 🎲 대조군(Baseline) 평가 및 시도 순서 무작위 교차 배정 (Randomization)

본인 모델의 성능 우수성을 입증하기 위해 대조군 알고리즘(S2E Only, ViNT/NoMAD 등)과 비교할 때 **순서 편향을 완전히 제거**해야 합니다.

```text
[ 잘못된 방식 ]: 대조군 A 5회 연속 테스트 ➔ 본인 모델 5회 연속 테스트
                 (배터리 전압 저하 및 모터 발열이 본인 모델에만 악영향을 줌)

[ 바른 방식 (Randomized Order) ]: 
  Trial 1: 대조군 A ➔ Trial 2: 제안 모델 (Latent) ➔ Trial 3: 대조군 B ➔ Trial 4: 제안 모델 (Latent)
```

* **배터리 전압 및 모터 온도 통제**:
  * Unitree Go2 배터리 잔량이 30% 이하로 떨어지면 모터 토크 출력이 하강하여 보행 안정성에 영향을 줍니다.
  * 모든 테스트는 **배터리 40% ~ 100% 구간에서만 진행**하며 정기적으로 완충 배터리로 교체합니다.

## 4. 📊 정량 평가 지표 측정 및 통계 처리 수칙 (Mean ± SD)

ICRA 심사에서는 단순 성공 횟수 표기보다 **통계적 분포와 신뢰 구간**을 중시합니다.

* **에피소드 시도 횟수**: 4개 시나리오별로 최소 **5회 이상 (총 20회 에피소드)** 수행합니다.
* **5대 핵심 정량 지표**:
  1. **성공률 (Success Rate, SR %)**: 목표 지점 반경 0.5m 이내 도달 비율.
  2. **경로 효율성 (SPL %)**: $\text{SPL} = \frac{1}{N} \sum_{i=1}^{N} S_i \frac{l_i}{\max(p_i, l_i)}$
  3. **평균 충돌 횟수 (Collision Count / Episode)**: 장애물 접촉 횟수.
  4. **주행 완료 시간 (Time to Goal, sec)**: 출발부터 목표 입선까지의 소요 시간.
  5. **사람 개입 횟수 (Human Interventions / E-Stop)**: 전복 위기 시 무선 조이스틱 E-Stop 클릭 횟수.
* **통계 표기 수칙**: 모든 정량 수치는 **평균 $\pm$ 표준편차 ($\text{Mean} \pm \text{SD}$)** 형식으로 제시합니다 ($95.0 \pm 2.2\%$).

## 5. 🔍 실패 모드(Failure Analysis) 및 경계 조건 스트레스 테스트

심사위원들은 완벽한 수치보다 **"어떤 한계 상황에서 실패하며, 하위 제어기(S2E)가 어떻게 안전하게 처리하는가"**에 더 큰 비중을 둡니다.

### 5.1 3대 실패 원인 분류표 (Failure Categorization)
1. **비전/인지 실패**: VLM이 막다른 길이나 피처를 잘못 인식하여 잘못된 경로 설정.
2. **로코모션/물리 실패**: 자갈이나 풀밭 지면 슬립으로 인해 발이 미끄러져 전복.
3. **연산/지연 실패**: 온보드 컴퓨팅 병목으로 VLM 추론 지연 시간이 길어져 반응이 늦어짐.

### 5.2 통제된 스트레스 테스트 진행
* **통신 신호 단절 테스트**: VLM 신호 출력을 의도적으로 1~2초간 멈추었을 때, 로봇이 하위 S2E 제어기(50Hz)의 힘으로 **제자리 안전 보행(Hovering/Stance)**을 유지하며 안전하게 대기하는지 확인.
* **광학 노이즈 테스트**: 카메라 렌즈에 직사광선이 비추는 조건에서 안전 정지 동작으로 이행되는지 확인.

## 🏃 6. 실물 로봇 테스트 4단계 실전 이행 수칙

1. **[준비 단계]**: 코스 규격 마스킹 테이핑 ➔ `record_experiment.sh` 세팅 ➔ 로봇 배터리 완충 (40~100% 유지).
2. **[실행 단계]**: 대조군과 제안 모델을 교차하며 코스당 5회 무작위 시도 (Randomized Trial).
3. **[로깅 확인]**: 시도 직후 성공/실패 여부, 충돌 횟수, E-Stop 개입 여부를 현장 평가 시트에 마킹 + `rosbag` 저장.
4. **[후처리 단계]**: `python3 scratch/calculate_icra_metrics.py`를 실행하여 Table 1 정량표($\text{Mean} \pm \text{SD}$) 및 2D 궤적 그래프 산출.
