### 🌐 1. [로봇 - Jetson - Docker - Server] 4-Tier 통신 파이프라인

* **🐕 1단계: 로봇 (Hardware)**
  * 관절 센서, 4D LiDAR(L2), Body IMU, Front RGB 카메라 하드웨어 송출 정상

* **💻 2단계: 젯슨 (Jetson Orin NX — Ubuntu 20.04)**
  * 공식 C++ 드라이버 직결 (**라이다 15Hz, IMU 500Hz, 카메라 30fps, 오도메트리 50Hz**)
  * 4대 센서 융합 기반 **RTAB-Map LIVO 50Hz** 고속 실시간 위치추정(SLAM) 가동
  * Host ↔ Docker 간 **0.1ms 초저지연 루프백 UDP IPC 브릿지** 체결 (유실율 0.00%)

* **📦 3단계: 도커 (Docker Sandbox — Ubuntu 24.04)**
  * 최신 24.04 ARM64 격리 환경 구축 (버전 충돌 원천 차단)
  * 서버 추론 지연(200ms) 실시간 위치 보정(**Causal Pose Warping**) 기반 50Hz 비동기 주행 엔진 구동
  * NetBird 14ms VPN으로 원격 GPU 서버와 실시간 통신 & 운동학적 정체 방지 안전 가드 탑재

* **🧠 4단계: 원격 서버 (Remote GPU — RTX Pro 6000)**
  * 720p 카메라 이미지 수신 ➔ **Qwen3-VL 멀티모달 AI**로 최적 서브골/주행 명령 고속 판단 및 송신
