# 📐 [Master Standard] Unitree Go2 ESCAPE-Nav 표준 기술 용어 및 하드웨어 동작 상태 사전

> **문서 목적**: 시스템 전반에서 모호한 표현을 배제하고, 연구원 및 Jetson/Docker AGY 간 완벽한 소통을 위한 단일 표준 기술 용어 체계(Single Technical Taxonomy)입니다.

---

## 1. 📋 표준 기술 용어 대조표

| 구분 | ❌ 금지/지양할 비기술적 표현 | ✅ 의무 사용할 표준 기술 명칭 | 물리적 실체 및 기술적 정의 |
| :--- | :--- | :--- | :--- |
| **로봇 전원/모터** | 모터 전원이 꺼진 상태 / 하드웨어 모터 전원 차단 | **로봇 본체 전원 인가 후 리모컨 포복(Prone) 와상 대기 상태** | 배터리 전원 ON 상태에서 리모컨으로 바닥에 엎드리게 하여 12개 모터가 바닥 착지 자세를 유지하는 상태 |
| **소프트웨어 안전** | 모터 안 돌게 하기 / 안전 모드 | **소프트웨어 제로 속도 안전 인터록 (Zero-Velocity Safety Clamping)** | 테스트 스크립트가 $v_x=0.0\text{ m/s}, \omega_z=0.0\text{ rad/s}$를 인가하여 로봇의 돌발 움직임을 원천 차단하는 로직 |
| **라이다 하드웨어** | 라이다 L1 / 내장 라이다 (모호한 표현) | **Unitree 4D LiDAR L2 (신형 4D 라이다)** | Go2 EDU Plus에 탑재된 $360^\circ \times 90^\circ$ 반구형 시야각 4D 라이다 |
| **라이다 점군 토픽** | `/utlidar/cloud` (기본 예제명) | **`/pointcloud`** | `unitree_lidar_ros2_node`가 UDP 6201에서 수신하여 실시간(15Hz) 퍼블리시하는 표준 토픽 |
| **오도메트리 토픽** | 라이다 SLAM 오도메트리 | **로봇 메인보드 DSP 하드웨어 융합 오도메트리 (`/odom`)** | Go2 메인보드 DSP가 1000Hz로 라이다+IMU+엔코더를 융합하여 50Hz로 송출하는 토픽 |
| **카메라 스트림** | 젯슨 로컬 웹캠 | **Go2 내장 전면 카메라 H.264 RTP 멀티캐스트 스트림 (`230.1.1.1:1720`)** | 메인보드 인가 시에만 송출되는 전면 초광각 720p 30fps 비디오 스트림 |
| **모터 제어 체계** | cmd_vel만 쏘기 | **이중 계층 모터 구동 체계 (Dual-Layer: ROS 2 `/cmd_vel` + CycloneDDS Sport API 1008)** | C++ 드라이버 유무와 무관하게 100% 모터 제어를 보장하는 호스트 브릿지 구조 |
| **VLM 모델 설정** | 모델 수동 하드코딩 | **VLM 모델 실시간 자동 감지 (Zero-Config Auto-Discovery via `GET /v1/models`)** | 서버 서빙 모델 변경 시 클라이언트 무수정 실시간 자동 바인딩 메커니즘 |
